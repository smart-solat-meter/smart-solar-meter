☀ Smart Solar Meter

Professional app for measuring, managing, and exporting data from solar panels and strings

✓ App Features 🌐 7 Languages

Main Features

📏

Solar Panel Measurement

Simple and accurate measurement of voltage, current, and resistance directly in the field. Choose which values you want to measure.

📷

Photos with String Label

Take a photo of a defect and the app automatically adds a label with the string and inverter name directly into the image.

📈

Export to Multiple Formats

Export measured data to different file types for further processing or archiving.

🟢

Critical Values and Automatic Detection

Set critical limits for voltage, current, and resistance. The app automatically alerts you to incorrect values.

🔎

OCR Scanning from Meter

Read values directly from the meter display using advanced OCR. Detailed OCR settings ensure reliable reading under any conditions.

✍

Notes for Strings

Add your own notes to each string and edit saved information at any time.

🔒

Bad Connector Marking

Quickly mark a string as having a bad connector with a single tap for fast defect tracking.

📌

Custom String Labeling

Choose the naming style: basic (A, B, C), advanced (A1, A2, B1), numeric, or fully custom according to your needs.
